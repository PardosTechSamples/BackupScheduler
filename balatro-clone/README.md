# Ante Run — Balatro-style HTML clone

Fan-made browser poker roguelike with the **full Balatro card set**, hosted as static HTML.

```bash
cd balatro-clone
python3 -m http.server 8080
# http://localhost:8080
```

## Full collection

Browse everything in-game via **Collection**.

## Rulebook-funded mechanics

- Score = Chips × Mult
- Level-1 hand bases and ante chip requirements
- Card modifiers (Bonus, Mult, Wild, Glass, Steel, Stone, Gold, Lucky)
- Seals & editions, consumable slots, booster packs
- Boss blinds, shop economy, Joker order (left → right)
